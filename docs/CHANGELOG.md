# Changelog

## [1.0.0] - 2026-10-15

### Added
- Initial release on CurseForge
- Real-time word suggestions (up to 5)
- Mouse wheel navigation
- Click-to-select functionality
- SCOWL 70K dictionary
- Prefix indexing (O(1) lookups)
- Levenshtein distance matching
- Error handling

### Features
- <1% CPU usage
- Dyslexic-friendly typo matching (distance=4)
- 60-second suggestion cache
- Early exit after 5 matches

### Known Limitations
- ChatFrame1 only (default chat)
- Click selection (no keyboard nav)
- SavedVariables not implemented yet
