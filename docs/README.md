# TypeSuggester Development

Real-time word suggestions addon for World of Warcraft Forever chat.

## Features

- Real-time suggestions (up to 5 words)
- Mouse wheel navigation
- Click to select
- SCOWL 70K dictionary
- <1% CPU usage (optimized)
- Dyslexic-friendly typo matching

## Installation

1. Download from CurseForge
2. Extract to `World of Warcraft\_classic_beta_\Interface\AddOns\`
3. Enable and reload

## Usage

- Type normally → suggestions appear
- Scroll wheel → navigate
- Click → insert word
- ESC → close dropdown
